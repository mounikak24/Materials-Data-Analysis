# Materials Data Analysis

## Overview

This project focuses on analysing Cu–Zn alloy datasets using Python and AI-assisted data collection. The objective is to preprocess materials datasets, perform exploratory data analysis (EDA), generate visualisations, and study material-property relationships for materials informatics applications.

## Objectives

- Collect Cu–Zn alloy datasets using multiple AI tools
- Clean and preprocess datasets for analysis
- Compare AI-generated datasets with literature data
- Perform exploratory data analysis (EDA)
- Generate statistical summaries of alloy properties
- Visualise trends and relationships between material properties

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Repository Structure

| File | Description |
|------|-------------|
| CuZn_AI_Data_Analysis (1).ipynb | Main notebook containing data preprocessing, analysis and visualisation |
| CuZn_Literature_Data.csv | Literature-based Cu–Zn alloy dataset |
| chatgpt data.csv | Dataset generated using ChatGPT |
| Gemini data.csv | Dataset generated using Gemini |
| Perplexity data (1).csv | Dataset generated using Perplexity |
| copiliite data.csv | Dataset generated using Microsoft Copilot |
| cu_zn report (1).pdf | Final project report |

## Key Outcomes

- Compared AI-generated datasets from multiple sources
- Performed data preprocessing and exploratory data analysis
- Computed statistical summaries for alloy properties
- Generated visualisations using Python
- Demonstrated an AI-assisted workflow for materials data analysis
